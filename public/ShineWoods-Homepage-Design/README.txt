SHINEWOODS — HOMEPAGE DESIGN PACK
=================================
Live website: https://shinewoods.vercel.app

WHAT IS IN THIS ZIP
  index.html
      Open this file in Chrome, Edge or Safari to view the
      homepage design (layout, type, cover video, photos).

  screenshots/
      Full-page desktop and mobile pictures of the live homepage.
      Use these if you only need images for a deck or print.

  media/, _next/, events/, icon files
      CSS, fonts, cover posters and cover video used on the page.

HOW TO OPEN
  1. Unzip the folder.
  2. Double-click index.html
     (or right-click → Open with → Google Chrome)

  Menu links (Talent, About, Apply…) open the live website.

This pack is the homepage design only — not the full portal.
